# Jarvis · Releases

Installer und Update-Kanal der Jarvis-App für Windows. Der Quellcode liegt in einem privaten Repository.

- **Installieren:** unter [Releases](../../releases/latest) die Datei `Jarvis_<Version>_x64-setup.exe` herunterladen und ausführen. Installiert wird pro Benutzer, ohne Administratorrechte.
- **Updates:** Die App prüft beim Start und alle sechs Stunden `latest.json` aus dem neuesten Release und bietet neue Versionen an.
- **Sicherheit:** Jede Version ist signiert. Die App installiert nur Dateien, deren Signatur zum eingebauten öffentlichen Schlüssel passt.
